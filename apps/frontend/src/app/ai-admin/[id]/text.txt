- prompt - large text field for the prompt template
prompt text: Prompts are instructions you give to a large language model (LLM) that tell it what to do. Much like asking someone for directions, the clearer and more specific your request, the better the response you’ll receive.

- max_tokens - integer field for maximum tokens
max_tokens text: Maximum number of tokens to generate.

- temperature - numeric field for temperature
temperature text: This value is passed through to the provider, and the valid range depends on the provider and model. For most providers, a value of 0 produces nearly deterministic output, while higher values introduce more randomness. It is recommended to configure either temperature or topP, but not both.

- top_p - numeric field for top_p
top_p text: Nucleus sampling. This value is passed through to the provider, and the valid range depends on the provider and model. For most providers, nucleus sampling (topP) is a number between 0 and 1. For example, a value of 0.1 means that only tokens within the top 10% of the probability mass are considered. It is recommended to configure either temperature or topP, but not both.

- frequency_penalty - numeric field for frequency_penalty
frequency_penalty text: The frequency penalty controls how likely the model is to repeat the same words or phrases. This value is passed through to the provider, and the valid range depends on the provider and model. For most providers, a value of 0 means no penalty is applied.

- presence_penalty - numeric field for presence_penalty
presence_penalty text: The presence penalty controls how likely the model is to repeat information already present in the prompt. This value is passed through to the provider, and the valid range depends on the provider and model. For most providers, a value of 0 means no penalty is applied.

- stop_sequences - text file field for stop_sequences
stop_sequences text: Stop sequences define where text generation should end. When set, the model stops generating text as soon as it produces one of the specified stop sequences. Providers may impose limits on how many stop sequences can be used. Example `'###', 'END', '\n\n\n'`

- seed - integer field for seed
seed text: This is the seed (an integer) used for random sampling. When set and supported by the model, it ensures that calls produce deterministic results.

- max_retries - integer field for max_retries
max_retries text: The maximum number of times to retry a request if it fails due to transient errors such as network issues or rate limiting. The default value is 2 retries.
